# How to Read
	Problem: 为什么要做这件事？ Previous Limitation: 以前的方法哪里不行？ Core Idea: 作者最核心的创新是什么？一句话说清楚。 Input → Output: 输入什么？ RGB / Language / State / Depth ... 输出什么？ Action / Action Chunk / Joint / EE Pose ... Architecture: VLM → Action Head → Robot 有什么特殊模块？ Data: 机器人数据？Human Video？Simulation？ 多少数据？几个机器人？ Training: BC / Imitation Learning / Diffusion / Flow / RL？ Experiment: 在哪些 benchmark？ 有没有 real robot？ 和谁比较？ Key Result: 它真正证明了什么？ Weakness: 它还有什么明显问题？ My Question / Idea: 如果让我继续做，我会做什么？
